# JLMS システム開発ドキュメント見本（教育用・実案件水準）

日本語学習管理システム（JLMS）を題材にした、**要件定義書 / 基本設計書 / 詳細設計書**のプロフェッショナルExcel完成見本です。  
研修・授業・社内教育で「本物の書き方・粒度・トレーサビリティ」を教える用途を想定しています。

## 成果物

| ファイル | 文書 | 文書番号 | 内容 |
|---|---|---|---|
| `01_要件定義書_JLMS.xlsx` | 要件定義書 | DOC-JLMS-RD-001 | 目的・As-Is/To-Be・UC・機能/非機能・画面帳票・IF・データ・移行運用・トレーサビリティ・承認 |
| `02_基本設計書_JLMS.xlsx` | 基本設計書（外部設計） | DOC-JLMS-BD-001 | アーキ方針・構成・モジュール・画面遷移・UI/帳票・論理モデル・IF/API・バッチ・セキュリティ・監視 |
| `03_詳細設計書_JLMS.xlsx` | 詳細設計書（内部設計） | DOC-JLMS-DD-001 | クラス/処理仕様・API詳細・画面イベント/状態・物理DB・バッチ詳細・メッセージ・状態遷移・試験対応 |

## 使い方（教育）

1. まず **要件定義書** で「何を作るか（Why/What）」を読む  
2. 次に **基本設計書** で「どう組み立てるか（How：外部仕様）」を追う  
3. 最後に **詳細設計書** で「どう実装するか（How：内部仕様）」まで落とす  
4. 各書の **トレーサビリティ** シートで、課題→要件→UC→画面→API→試験の縦糸を確認する

## 再生成

```bash
cd docs/japanese-design-templates
python3 generate_design_docs.py
```

依存: `openpyxl`
